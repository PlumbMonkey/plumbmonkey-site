# Legacy Plumbmonkey landing page

This folder preserves the original static landing page.

- `index.html` is the last active legacy version.
- `index.html.backup` is its earlier backup.
- Shared legacy assets remain in the repository's `assets` and `styles` folders.

The active website is the Next.js application in `app/`. GitHub Pages should
publish the generated `out/` folder through `.github/workflows/deploy.yml`.
